# MarketDay seller application preview

The seller application page is `seller-application.html`. It lays out the requested fields: seller full name, store name, Ghana Card front and back, selfie, and general location (region and town/city).

**This is only a static form preview.** The Ghana Card and selfie upload controls are deliberately disabled. The form does not submit or store any information. Do not add real seller identity documents or personal information to this GitHub Pages prototype.

Before enabling applications, implement a secure private backend and document upload flow: obtain informed consent; explain the verification purpose; restrict staff access; encrypt uploads and backups; set retention/deletion and incident-response policies; and review Ghana's applicable data-protection requirements. Avoid collecting precise home/GPS location unless demonstrably necessary. Assess whether a reputable identity verification service can verify the seller without MarketDay retaining card images.
